# 🤖 Basic Chatbot using Python

A simple **rule-based chatbot** built using Python as part of the **CodeAlpha Python Programming Internship**.

---

## 📌 Project Overview

This chatbot interacts with users through the command line by responding to predefined questions and greetings. It uses conditional statements, functions, and loops to provide appropriate responses until the user chooses to exit.

---

## ✨ Features

- 👋 Greets users with friendly responses
- 💬 Answers predefined questions
- 🤖 Explains basic Python and AI concepts
- 🙏 Responds to gratitude
- 🆘 Provides a help command
- 🚪 Exits the chatbot when the user types **"bye"**
- ❓ Handles unknown inputs gracefully

---

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code

---

## 📚 Python Concepts Used

- Functions
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`)
- User Input & Output
- Function Return Values (`return`)
- String Methods (`lower()`)
